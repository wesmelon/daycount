# Daycount — Daily streaks

[Open the streak tracker](https://wesmelon.github.io/daycount/streaks/)

Track daily habits, backfill history, browse a calendar, and earn milestone badges. See [streaks/README.md](streaks/README.md) for usage and local development. GitHub Pages serves `master` at the repository root; `index.html` redirects to the app in `streaks/`.

## Original countdown app

The original Go/AngularJS countdown code has moved to [daycount-countdown-backup](https://github.com/wesmelon/daycount-countdown-backup). That repository includes an exact source snapshot in `legacy-original/`, a hash manifest, and a modern event countdown app in `docs/` with T−99 / Today / T+12 displays.

Original history remains available here at commit `a49128db16bb410cc657adffcd803934daeedc74`. No existing streak storage keys, paths, or app files were changed by the separation.
